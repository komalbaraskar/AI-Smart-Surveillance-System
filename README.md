# 🛡️ AI Smart Surveillance System

An **AI-powered real-time surveillance system** that detects, tracks, and analyzes people using computer vision and machine learning.

### 🚀 Features
- 👤 Real-time person detection using **YOLOv8**
- 🎯 Multi-object tracking with **Deep SORT**
- 🙂 Face recognition
- 👥 People counting & crowd detection
- ⏱️ Loitering detection
- 🔥 Activity heatmap
- 🚨 Automated security alerts
- 📊 Flask monitoring dashboard
- 🍃 MongoDB data logging
- 🐳 Docker containerization

### 🛠️ Tech Stack

**Python • OpenCV • YOLOv8 • Deep SORT • Flask • MongoDB • Docker • Git**

### 🔄 Workflow

```text
Camera → YOLOv8 → Deep SORT → Activity Analysis
                     ↓
              Alerts & Heatmap
                     ↓
               MongoDB + Dashboard
```

### ▶️ Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

```text
http://localhost:5000
```

### 🎯 Objective

To transform traditional CCTV monitoring into an **intelligent automated surveillance system** capable of detecting, tracking, analyzing, and alerting about unusual activities.

**Detect → Track → Analyze → Alert → Store**
